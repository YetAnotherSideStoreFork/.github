## Why?
I didn't like that some PRs were left stale (particularly the one that fixes signing Extensions), so I decided to make this fork for myself. Every night changes get pulled in from upstream. If any conflicts arise, I will fix them.

Don't even try asking for help for it from the SideStore Team, I am in no way affiliated with them, I'm just a fops with weird passions.
